# OCBC Indonesia copy reference

- Display name and logo alt text: **OCBC**. Use **OCBC Indonesia** in prose to distinguish the Indonesian bank from the group. Use **PT Bank OCBC NISP Tbk** when the legal entity name is needed, subject to approved wording.
- Keep headings and labels editable. Use the bundled wordmark rather than typesetting a substitute.

Sample labels (not official slogans): **Ringkasan kinerja** / **Performance summary**; **Lihat detail** / **View details**. Use full currency values, e.g. **Rp 1.250.000**. Use approved campaign copy and disclosures when supplied.
